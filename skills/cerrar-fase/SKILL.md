# Cerrar una fase

1. Lee AGENTS.md, [el estándar del proyecto](../../CALIDAD-Y-SEGURIDAD.md) y la fila de la fase en PLAN.md. Comprueba cada entregable autorizado contra los criterios de cierre.
2. Si hay código, ejecuta formato, lint, tipos, pruebas y compilación de producción según corresponda. Aplica las comprobaciones del estándar para los flujos afectados. Registra el resultado y el motivo de cada comprobación pendiente.
3. Actualiza el estado en PLAN.md con el resultado verificado. Añade a MEMORY.md las decisiones importantes que el usuario haya confirmado.
4. Comunica el resultado, las comprobaciones y lo pendiente. El cierre de una fase no autoriza la siguiente.
